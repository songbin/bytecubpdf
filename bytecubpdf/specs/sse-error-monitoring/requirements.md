# 需求文档: SSE翻译错误监控与展示

## 1. 介绍
在PDF翻译过程中，实时监控SSE流返回的错误信息，当检测到错误时，通过错误按钮向用户展示详细的错误列表，帮助用户了解翻译过程中的质量问题。

## 2. 需求与用户故事

### 需求 1: 错误信息收集与存储
**用户故事:** 作为PDF翻译用户，我希望建立一个能够实时收集翻译过程中的错误信息的机制，以便在翻译过程中或翻译完成后能够查看所有错误。

#### 验收标准
- **WHEN** SSE连接收到包含 `errors` 字段的消息时，**THEN** the system **SHALL** 将 `errors` 数组中的所有错误消息收集到错误列表中
- **IF** `errors` 数组为空，**THEN** the system **SHALL** 不进行任何操作
- **IF** 同一个错误消息重复出现，**THEN** the system **SHALL** 允许重复记录（不进行去重）

### 需求 2: 错误按钮显示
**用户故事:** 作为PDF翻译用户，我希望在检测到错误时能够立即看到一个明显的错误提示按钮，以便我知道翻译过程中出现了问题。

#### 验收标准
- **WHEN** 错误列表中至少有一条错误时，**THEN** the system **SHALL** 在翻译按钮左侧显示错误按钮
- **IF** 错误列表为空，**THEN** the system **SHALL** 隐藏错误按钮
- **WHEN** 错误按钮显示时，**THEN** it **SHALL** 使用红色样式并包含错误图标
- **WHEN** 错误按钮显示时，**THEN** it **SHALL** 显示当前错误数量，格式为 "错误 (N)"
- **IF** 翻译完成但存在错误，**THEN** the error button **SHALL** 继续保持显示
- **WHEN** 用户点击错误按钮时，**THEN** the system **SHALL** 打开错误详情对话框

### 需求 3: 错误详情对话框
**用户故事:** 作为PDF翻译用户，我希望点击错误按钮后能够在一个对话框中查看所有详细的错误信息，以便了解具体出现了哪些问题。

#### 验收标准
- **WHEN** 用户点击错误按钮时，**THEN** the system **SHALL** 显示一个模态对话框
- **WHEN** 对话框显示时，**THEN** it **SHALL** 包含以下内容：
  - 标题："翻译错误详情"
  - 错误总数统计文本
  - 按顺序列出所有错误消息
- **WHEN** 错误列表显示时，**THEN** each error **SHALL** 以独立行显示
- **IF** 错误列表为空，**THEN** the dialog **SHALL** 显示"暂无错误信息"提示
- **WHEN** 用户关闭对话框时，**THEN** the system **SHALL** 关闭对话框但不删除错误信息

### 需求 4: 错误状态生命周期管理
**用户故事:** 作为PDF翻译用户，我希望错误信息的管理与翻译过程保持同步，确保错误状态的准确性。

#### 验收标准
- **WHEN** 开始新的翻译任务时，**THEN** the system **SHALL** 清空之前的错误列表
- **WHEN** 翻译任务被终止时，**THEN** the system **SHALL** 保持当前的错误列表不变
- **WHEN** 翻译任务完成时（无论成功或失败），**THEN** the system **SHALL** 保持当前的错误列表不变
- **IF** 文件列表发生变化（上传新文件），**THEN** the system **SHALL** 清空错误列表
